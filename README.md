## 📘 Descripción general del sistema
Este proyecto es un prototipo inicial de un sistema orientado a objetos para la agencia de turismo "Llanquihue Tour". Su propósito principal es digitalizar y estructurar la información de las personas vinculadas a la organización (clientes, guías, etc.), automatizando registros y mejorando la trazabilidad de los datos mediante buenas prácticas de programación en Java.

---

## 🧱 Estructura general del proyecto

El proyecto está organizado en los siguientes paquetes:

* **`app`**: Contiene la clase principal para la ejecución del sistema.
    * `Main.java`: Punto de entrada del programa.
* **`model`**: Contiene las clases del dominio del problema, aplicando principios de encapsulamiento, herencia y composición.
    * `Persona.java`: Clase base general.
    * `Direccion.java`: Clase integrada mediante composición.
    * `Contacto.java`: Clase integrada mediante composición.
    * `Guia.java`: Clase que hereda los atributos de Persona.
